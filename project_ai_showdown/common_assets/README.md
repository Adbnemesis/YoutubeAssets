# 🎨 Common Assets Folder

This directory stores reusable visual and audio assets for **The AI Showdown** video production:

* `avatars/`: Character avatars for Claude (#1), Kimi (#2), ChatGPT (#3), Qwen (#4), Gemini (#5), Llama (#6), and Grok (#7).
* `sound_effects/`: Bell rings, debate timers, buzzer sounds, whoosh transitions (`whoosh.mp3`), elimination pop SFX (`error.mp3`), and background debate music tracks.
* `overlays/`: Lower-third speaker graphics, rank badges (#1-#7), VS logos, and eliminated stamps.
* `backgrounds/`: Futuristic debate stage backgrounds, Chibi survival island stages, and 3D virtual studios.

# Meme Timing Instruction Guide for Any Video

Use memes as **supporting visual beats**, not as the main content. The goal is to improve retention, emphasis, and humour without distracting from the message.

## Core rule

Insert a meme only when it **adds value** to one of these:

* a joke lands
* a strong opinion is made
* a surprising fact appears
* the pacing needs a quick reset
* the speaker says something relatable
* the video risks feeling repetitive or heavy

## Timing rules

* Place memes **after a key line**, not before it.
* Keep them short: **0.3–1.5 seconds** for quick reaction memes, **1.5–3 seconds** for stronger punch-ins.
* Use memes at natural pauses, sentence endings, or when the speaker shifts to a new point.
* Never interrupt a sentence unless the interruption is itself part of the joke.
* Avoid stacking too many memes close together. Leave breathing room.

## When to use a meme

Use a meme when:

* the line is especially funny, awkward, dramatic, or absurd
* the audience would naturally think of the meme themselves
* the video needs a pattern break
* there is a strong contrast between what is said and what is shown
* the moment is emotionally charged and a meme can amplify it

## When not to use a meme

Do not use a meme when:

* the speaker is explaining something important
* the moment requires trust, seriousness, or clarity
* the visual already contains enough energy
* the meme would cover important text, face, chart, or action
* the joke would feel forced or outdated
* it would slow the pacing instead of improving it

## Style rules

* Memes should feel **native to the edit**, not pasted on top.
* Match the meme to the emotion of the moment:

  * disbelief
  * confusion
  * victory
  * panic
  * awkwardness
  * revenge
  * disappointment
  * overconfidence
* Use subtle motion, scale, pop-in, or bounce only if it fits the tone.
* Keep meme placement clean and readable.
* Do not let the meme hide subtitles or the main subject.
* Avoid overusing the same meme format repeatedly.

## Best meme placement pattern

A strong structure is:

**setup → punchline → meme reaction → return to flow**

Example:

* speaker builds a point
* speaker drops a funny or shocking line
* meme appears for a quick reaction
* edit returns immediately to the main video

## Frequency guideline

For a normal short-form or fast-paced video:

* use memes sparingly
* aim for **one meme every 15–40 seconds**, only if the video needs it
* for high-energy content, you can increase frequency, but only if pacing still feels clean

## Meme quality checklist

Before adding a meme, ask:

* Does this improve the joke or moment?
* Is the timing exact?
* Does it help retention?
* Will it still make sense without extra explanation?
* Does it fit the tone of the video?
* Will it distract from the main message?

If the answer to any of these is no, skip it.

## Copy-paste instruction for the editor

Add memes only at moments where they strengthen humour, emphasis, or pacing. Place them after key lines or natural pauses, not in the middle of important explanations. Keep each meme short, visually clean, and relevant to the moment. Never cover essential visuals, subtitles, or text. Use memes sparingly so they feel intentional, not spammy. Match the meme type to the emotion of the scene, and return immediately to the main flow after each meme. Prioritise clarity, timing, and retention over quantity.

## Best practical rule

If a meme does not make the video **funnier, clearer, or more watchable**, leave it out.

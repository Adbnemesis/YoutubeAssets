# NEMI EXPLAINS — REEL FORMATS & TEMPLATE SCHEMAS

## 1. The 10 Core Recurring Formats

1. **The System Explorer (Flagship):**
   * *Structure:* High-stakes resource consumption → Who cleans it up? → Interactive guess → Reversal → Mark-and-sweep tree trace → Rapid cleanup → Payoff.
   * *Examples:* Garbage Collection, DNS Lookup, TCP Handshake.

2. **The 1-Line Outage:**
   * *Structure:* High-profile outage ($10M lost) → 1 innocent line of code shown → Nemi guesses the bug → Trap revealed → Fixed version.
   * *Examples:* Knight Capital 2012, Cloudflare ReDoS, AWS S3 typo.

3. **Algorithm Duel (Race Format):**
   * *Structure:* Problem shown → Brute Force ($O(N^2)$) vs Optimal ($O(N)$) racing side-by-side → Brute force stalls → Optimal wins with spring animation.
   * *Examples:* Two Sum, Sorting algorithms, Tree search.

4. **Under The Hardware Hood:**
   * *Structure:* Software command executes (`malloc(1024)`) → Camera zooms into RAM / CPU registers → Silicon gates illuminate → Return value.
   * *Examples:* How CPU Cache works, How SSD NAND writes blocks.

5. **Spot The Trap with Nemi:**
   * *Structure:* 4 lines of code → "What does this print?" → 3s timer → Nemi selects Option A → Option B revealed with AST breakdown.
   * *Examples:* `[1,2,3] + [4,5,6]`, `typeof null`, `0.1 + 0.2 === 0.3`.

6. **Protocol Anatomy:**
   * *Structure:* Client sends packet → Wireshark packet view explodes into visual fields → Server responds → Handshake complete.
   * *Examples:* HTTPS TLS 1.3, WebSockets, HTTP/2 multiplexing.

7. **The 30-Year-Old Bug / Quirk:**
   * *Structure:* Modern language strange behavior → Historical reason from 1995 Netscape or C K&R → Why it can never be removed.
   * *Examples:* `typeof null === 'object'`, `Date.getMonth()` 0-indexed.

8. **Scale In Seconds:**
   * *Structure:* 1 request (easy) → 10,000,000 requests (collapse) → Architecture pattern added (Load Balancer / Sharding) → Stability restored.
   * *Examples:* Discord voice gateway, Uber spatial H3 indexing.

9. **Refactor Battle (Junior vs Senior):**
   * *Structure:* 25 lines of nested `if/else` spaghetti → Code collapses with spring physics → Replaced with clean Strategy / Pattern in 4 lines.

10. **Everyday Tech X-Ray:**
    * *Structure:* Tap phone on NFC terminal → Radio waves induce current in card chip → Cryptographic challenge verified in 80ms.

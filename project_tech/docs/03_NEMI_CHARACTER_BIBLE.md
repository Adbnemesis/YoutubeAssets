# NEMI EXPLAINS — NEMI CHARACTER BIBLE

## 1. Character Identity & Visual Design
* **Name:** Nemi
* **Species / Persona:** Clever, highly curious developer monkey wearing an oversized dark hoodie with electric yellow drawstrings.
* **Key Visual Elements:**
  * Dark Charcoal Fur (`#2B2D42` / `#3D405B`)
  * Peach Heart-Shaped Face Mask (`#FFCDB2`) with subtle cheek blush
  * Oversized Round Glasses with Yellow Frames (`#FFD166`) and Cyan Lenses
  * Spiky hair tufts on top
  * Dark developer hoodie with yellow drawstring aglets

---

## 2. Nemi's Role in the Story
> **"Nemi is NOT the teacher. Nemi is the VIEWER'S AVATAR."**

Nemi experiences the code alongside the audience:
1. **Curiosity:** Puzzles over confusing code or spikes in resource usage.
2. **Assumption / Guess:** Makes the intuitive guess that 90% of junior/mid developers would make.
3. **Surprise / Reversal:** Realizes the unexpected runtime behavior (eyes widen, glasses glint).
4. **Active Agency:** Sweeps garbage, points out anomalies, triggers cleanups.
5. **Satisfaction / Celebration:** Smiles smugly or celebrates clean code.

---

## 3. Pose State Dictionary
* `thinking`: Neutral analytical head tilt, slight float.
* `puzzled`: Tilted glasses, wavy mouth, curious brow.
* `pointing`: Extended arm & finger targeting a specific card or anomaly.
* `shocked`: Wide open eyes, O-shaped mouth.
* `aha`: Confident smirk, glasses glint specular flare, floating lightbulb 💡.
* `smug`: Knowing smile, arms crossed, master developer confidence.
* `explaining`: Hand gesturing towards active visual diagram.

---

## 4. Strict Mascot Rules
* ❌ Nemi NEVER reads long mechanical definitions in speech bubbles.
* ❌ Nemi speech bubbles must be short and punchy (≤ 6 words, e.g., *"Because I'm not doing it"*, *"That one!"*, *"Wait... Oh"*, *"Bye. 👋"*, *"Much better!"*).
* ❌ Nemi is never placed where he obstructs central data flows or technical diagrams.

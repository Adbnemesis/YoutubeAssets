# NEMI EXPLAINS — CONTENT PILLARS & EDITORIAL MIX

## 1. Editorial Distribution Strategy
To ensure both algorithmic virality and high-ticket B2B commercial value, Nemi Explains content is divided into 6 distinct pillars:

| Pillar | Focus Area | Audience Appeal | Shareability Driver | Target % |
|:---|:---|:---|:---|:---:|
| **1. Under The Hood** | Memory allocators, V8 engine, GPU pipelines, SSD NAND gates, CPU branch predictors. | Engineering curiosity, system internals. | "Mind blown" technical clarity. | **30%** |
| **2. Internet Infrastructure** | DNS resolution in 15ms, Cloudflare Anycast, WebSockets, TCP vs QUIC, TLS 1.3 handshake. | Backend/DevOps, networking engineers. | Essential architecture diagrams. | **20%** |
| **3. Code That Tricks You** | JS type coercion, Python default mutable parameters, Go goroutine leaks, C pointer math. | All developers, interview candidates. | Ego challenge, debate in comments. | **15%** |
| **4. DSA & Algorithm Duels** | Two Pointers vs Nested Loops, BFS vs DFS, Hash Map collisions, Tree traversal. | LeetCode grinders, CS students. | Clear visual intuition. | **15%** |
| **5. System Design in 30s** | How Discord handles 5M voice users, WhatsApp 2B messages, Uber driver dispatch. | Tech leads, senior engineers. | Real-world engineering scale. | **10%** |
| **6. Everyday Tech Mysteries** | How GPS uses 4 satellites, How touchscreens work, How QR codes error-correct. | Broad tech enthusiasts, founders. | Relatable everyday fascination. | **10%** |

## 2. Topic Qualification Criteria
Before greenlighting any Reel topic, it must pass 3 filters:
1. **Can it be drawn?** If the concept cannot be expressed as a moving vector graph/diagram in Remotion, reject it.
2. **Is there an intuitive wrong assumption?** (e.g. "You'd think X gets deleted, but actually Y happens").
3. **Does it resolve in under 25 seconds?** If it requires a 5-minute preamble, split it into a 3-part micro-series.

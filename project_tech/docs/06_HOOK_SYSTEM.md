# NEMI EXPLAINS — HOOK SYSTEM & FIRST 3 SECONDS TAXONOMY

## 1. The Fatal Flaw of Traditional Educational Hooks
Traditional tech videos start with:
* *"Welcome back to my channel"*
* *"Today we are going to learn how Garbage Collection works in V8"*
* *"Understanding Memory Management in JavaScript"*

**Result:** 70%+ of viewers swipe away before 1.5 seconds. The brain has no reason to invest attention in a lecture.

---

## 2. The 5 Nemi High-Retention Hook Archetypes

### Archetype 1: The Imminent Catastrophe (Resource Surge)
* **Visual:** Meters climbing rapidly, memory objects flooding the screen, alert flashing.
* **Narration:** *"Your JavaScript keeps making stuff. A LOT of stuff."*
* **Psychology:** Imminent crisis creates immediate stakes.

### Archetype 2: The Counter-Intuitive Anomaly
* **Visual:** Code snippet with obvious outcome that fails: `[1, 2, 3] + [4, 5, 6]`.
* **Narration:** *"90% of developers guess this output wrong."*
* **Psychology:** Intellectual ego challenge.

### Archetype 3: The Impossible Scale Question
* **Visual:** Single phone typing a message vs 2,000,000,000 active nodes.
* **Narration:** *"How does WhatsApp deliver 100 billion messages a day without crashing?"*
* **Psychology:** Awe and curiosity.

### Archetype 4: The Hardware/Software Contrast
* **Visual:** C++ manual `delete` vs JavaScript magic heap.
* **Narration:** *"C++ forces you to free every byte manually. Why does JavaScript let you forget?"*
* **Psychology:** Comparative mental model.

### Archetype 5: The Microsecond Timeline
* **Visual:** Time scrubbing from `0.0ms` to `15.4ms`.
* **Narration:** *"This is what happens inside your router in the 12 milliseconds after you hit Enter."*
* **Psychology:** Microscopic journey.

---

## 3. Strict Hook Rules
1. **Motion in Frame 0:** No static title cards. Elements must pop, bounce, or cascade from frame 0.
2. **Question by Second 3.5:** The core mystery must be established within the first 100 frames.
3. **Mascot Reacts Immediately:** Nemi is in frame 0 mirroring the viewer's reaction.

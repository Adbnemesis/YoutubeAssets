## 1. FROZEN SYSTEMS (Do NOT Redesign Casually)

These systems have undergone rigorous multi-version testing (V01–V11) and have proven effective across audience retention, broadcast audio standards, and visual clarity:

* `[FROZEN]` **Dual Canvas Architecture:**
  - Warm Designer Cream (`#F8F6F0`) for Hook, Problem, and Payoff scenes.
  - Obsidian Dark Studio (`#0D1117`) for internal runtime execution, binary grids, and global network systems.
* `[FROZEN]` **Brand Accents & Typography:**
  - Electric Yellow (`#FFD166`), Tech Cyan (`#06B6D4`), Emerald Live (`#10B981`), Coral Bug (`#F43F5E`).
  - Inter 900 Black headlines with negative tracking (`-2px`); JetBrains Mono Bold for code/metrics/IPs.
* `[FROZEN]` **Nemi Character Role:**
  - Nemi is the **Audience Avatar** (curious, clever, relatable, slightly mischievous).
  - Nemi **NEVER** lectures technical definitions.
  - Nemi speaks at most **2–3 punchy reactive interjections** per short Reel.
* `[FROZEN]` **Voice Performance & Speaker Orchestration:**
  - Chatterbox Neural TTS with `tech_voice_profile.json` normalized to `-16.0 LUFS`.
  - Coherent long-form narrator performance blocks (4–7 blocks).
  - Strict deterministic zero-overlap state machine: `accidental overlap == 0.00ms`.
  - Pre-render automated validation via Python validators.
* `[FROZEN]` **Dynamic Audio Mastering:**
  - FFmpeg sidechain ducking (`volume: 0.23`, `threshold: 0.06`, `attack: 15ms`, `release: 300ms`).
  - Master Broadcast Loudness: `-15.5 to -14.0 LUFS` | `True Peak ≤ -1.5 dBTP`.
* `[FROZEN]` **Continuous World & Camera Navigation:**
  - Virtual camera transforms (`CameraPush`, `CameraFollow`, `PanTo`, `ZoomThrough`) inside unified vector environments rather than slide-based wipes.
* `[FROZEN]` **Story Velocity & Runtime Window:**
  - Strict target runtime: **18.0s – 24.0s** (Ideal: **19.5s – 22.0s**).
  - Zero classroom recap cards ("What you learned", "Summary", "Steps").

## 4. REJECTED SYSTEMS (Known Content Killers — NEVER Return)

* `[REJECTED]` **Static Title Intro Card (0–2s):**
  - Opening with a static title before anything moves kills retention. Frame 0 must begin with immediate visual action.
* `[REJECTED]` **Accidental Speaker Overlap:**
  - Narrator and Nemi talking at the same time creates muddy, unintelligible audio.
* `[REJECTED]` **Generic Tech Stock Cyber B-Roll:**
  - Glowing matrix grids and floating binary stock footage that fail to represent real conceptual mechanics.
* `[REJECTED]` **Long Educational Outros / "Follow For More":**
  - Lecturing the viewer or demanding follows at the end causes immediate swipe-aways. End crisp on the payoff.

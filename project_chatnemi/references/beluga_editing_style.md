# 🐋 The Beluga Editing Style: Master Guidelines

This document serves as the master reference for the Beluga editing style. Every video's script will be different, but these core stylistic laws must ALWAYS be followed to ensure the pacing, humor, and visual aesthetic remain consistent across all episodes.

## 1. Visual Framing: The "Algorithmic Dynamic Crop"
The camera must never show a static, full-screen Discord window. The visual humor relies on extreme zooming that dynamically reacts to the text.

*   **The Perfect Bounding Box:** The camera must calculate the exact bounding box of the active text and avatar, and scale it up to fill the 1920x1080 frame.
*   **The 1-Word Zoom:** If a character sends a single short word, its bounding box is tiny. The camera must zoom in massively (e.g., 8x-10x scale) so that single word fills the entire screen.
*   **The Expanding Crop (Stacking):** When a character rapid-fires multiple messages, the messages stack vertically. The camera must dynamically "zoom out" (expand the crop) just enough to keep all active lines within the frame.
*   **The Speaker Wipe:** The instant a *different* character speaks, the screen must completely wipe the previous character's messages. The camera cuts directly to a tight crop of the new character's text. No lingering chat history.

## 2. Audio & Sync: Relentless Sound Design
Every visual change on screen must be hard-synced to a sound effect. There is no silent text.

*   **Message Delivery:** The standard Discord ping plays exactly when a normal message appears.
*   **The Vine Boom:** Used heavily for punchlines, sudden realizations, or incredibly stupid answers. This is the primary comedic sound effect.
*   **Keyboard Clacking:** Must play *only* while the `[character] is typing...` indicator is on screen. The audio must cut off perfectly on the exact frame the message appears.
*   **Silence / Record Scratch:** Used to abruptly kill the pacing when a character says something that brings the conversation to a screeching halt.

## 3. Pacing & Timing
Beluga videos are designed for maximum retention with zero dead air. The pacing is relentlessly fast.

*   **Rapid-Fire Delivery:** Contiguous texts from the same user must appear with only a **0.2s to 0.5s** delay.
*   **Suspense Building:** The typing indicator (`... is typing`) should be used specifically to build 1-2 seconds of suspense before dropping a major punchline or absurd answer.

## 4. Cutaways (B-Roll Integration)
To break the visual monotony of the Discord UI, the edit must frequently use hard-cuts to full-screen images or stock videos.

*   **Literal Interpretations:** When a specific noun, place, or object is mentioned in a funny context, cut away to a full-screen image or stock video of that thing for 1-2 seconds.
*   **Abruptness:** These cutaways must be abrupt and fill the entire screen, completely replacing the Discord UI momentarily before snapping back to the chat.

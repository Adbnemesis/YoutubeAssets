# Workspace Rules for AI Showdown

All AI Showdown video production tasks MUST strictly follow the specifications in `project_ai_showdown/EPISODE_PRODUCTION_DOCTRINE.md`:

1. **Episode Asset Checklist**: Every episode must include `video_plan.json`, `script.json`, `metadata.json`, `assets/`, `audios/`, `transcripts/`, and `final_video.mp4`.
2. **Episode Participation Filtering**: Roster sidebar MUST contain ONLY active speakers for that episode.
3. **Official Brand Logos**: Use ONLY the user-provided official brand logos in `common_assets/logos/original/`.
4. **Fixed Speech Bubbles**: Use fixed 540x180px speech bubbles with 15-word paged text refresh and simplistic `'Inter'` font.
5. **Keyframed Anime Poses**: Hand movements must use 50-frame pose holds (~1.6s beats), never continuous waving.


## Brawl Stars Project Rules
- For any tasks within the `project_brawlstars` directory, strictly update and rely on the components inside `project_brawlstars/components`. Do not mix or use global components from other projects for these specific video templates.

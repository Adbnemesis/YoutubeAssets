# "I Ragebaited AI" — YouTube Channel Prompt Blueprint

## 0. CHANNEL IDENTITY PROMPT (run once, keep the output as a reference doc)

```
You are a YouTube channel strategist. I'm building a channel called
"I Ragebaited AI." Premise: [describe exactly what happens in your videos —
e.g. "I give chatbots deliberately infuriating, absurd, or impossible prompts
and film their reactions / my reactions to their responses" — be specific,
since this shapes everything downstream].

Define:
1. A one-paragraph channel mission statement
2. Target audience (age range, interests, what else they watch)
3. Tone (pick 2-3: chaotic / deadpan / satirical / wholesome-troll / unhinged / etc.)
4. 5 recurring video "pillars" or series formats
5. A consistent visual/verbal signature (recurring phrase, sound cue, on-screen gag)
6. 3 competitor/adjacent channels and what I should do differently

Output as a short brand doc I can paste into future prompts as context.
```

---

## 1. IDEA GENERATION PROMPT

```
Channel context: [paste your Channel Identity Doc from Step 0]

Generate 15 video ideas for "I Ragebaited AI."
For each idea, include:
- Hook/title (under 60 characters, curiosity or rage-bait driven)
- One-line concept
- The specific "ragebait" angle — what makes it funny, chaotic, or clip-worthy
- Estimated difficulty to produce (Easy / Medium / Hard)
- Predicted audience reaction (laugh / cringe / shock / relate)

Rules:
- No two ideas should use the same AI-interaction gimmick twice
- At least 3 ideas should be "series-starter" format (repeatable weekly)
- At least 2 should be timely/trend-jackable (tie to current AI news or memes)
- Flag anything that could cross into harassment, misinformation, or targeting
  a real named individual — I want spicy, not genuinely harmful
```

---

## 2. SCRIPT GENERATION PROMPT

```
Channel context: [paste Channel Identity Doc]
Chosen idea: [paste one idea from Step 1]
Video length target: [e.g. 8–12 minutes]

Write a full script with:
1. HOOK (first 15 seconds) — must state the premise and create a curiosity gap
2. SETUP (30–60 sec) — establish rules of the "game" for viewers
3. MAIN BODY — broken into labeled beats/segments, each with:
   - What I say/do
   - What the AI's response should illustrate (describe the *type* of
     reaction I'm looking for, not a fabricated fake transcript)
   - A suggested reaction line or joke for me to say
4. MID-ROLL retention hook (if 8+ min, add a "wait, it gets worse" beat)
5. OUTRO — CTA (subscribe/comment prompt) tied to the video's theme

Format: use markdown headers per segment so it's easy to read on a teleprompter.
Keep my on-camera voice conversational, not scripted-sounding.
```

---

## 3. EDITING RULES / POST-PRODUCTION PROMPT

```
Channel context: [paste Channel Identity Doc]
Script: [paste finished script from Step 2]

Generate an editing brief with:
1. Pacing guide — where to cut fast vs. let a moment breathe (map to script beats)
2. B-roll / cutaway suggestions per segment
3. Text-on-screen moments — exact wording + where they should appear
4. Sound design cues — stingers, silence beats, meme sounds (describe function,
   not copyrighted track names)
5. Thumbnail-worthy freeze-frame moments (timestamp guess + why)
6. Suggested cold-open cut (which segment to tease at 0:00 before intro)
7. A retention checklist (pattern interrupts every ~30–45 sec)

Output as a numbered shot-list style doc an editor could follow without
having watched the raw footage.
```

---

## 4. METADATA / SEO PROMPT

```
Channel context: [paste Channel Identity Doc]
Script: [paste finished script]

Generate:
1. 8 title options (mix of curiosity-gap, rage-bait, and clear-value styles),
   each under 60 characters
2. A 150-word YouTube description with:
   - First 2 lines optimized for search + suspense (visible before "show more")
   - Natural keyword inclusion (no stuffing)
   - CTA + relevant links placeholder
3. 15 tags (mix of broad + specific + trending AI terms)
4. 3 thumbnail text options (max 4 words each) + a visual concept per option
5. A community-tab teaser post to publish 1 hour before the video goes live
6. Pinned comment copy designed to boost engagement (question, not statement)
```

---

## 5. (OPTIONAL) SERIES CONSISTENCY PROMPT

Run this every 5–10 videos to keep the channel coherent as it grows.

```
Channel context: [paste Channel Identity Doc]
Here are my last 5 video titles + one-line summaries: [paste]

Audit for:
- Repetition/fatigue in format
- Whether the "ragebait" angle is escalating in a sustainable way or
  needs a reset
- 3 fresh format twists to reintroduce novelty
- Any tonal drift from the original channel identity
```

---

### How to use this
1. Run Step 0 once, save the output.
2. For every new video: Step 0 doc → Step 1 (pick one idea) → Step 2 → Step 3 → Step 4, pasting forward each time.
3. Run Step 5 periodically as a channel health check.
